# Qodex 本地完整工作台

本版以整合后的 main `1768f96` 为基线，在独立的 `codex/qodex-web-integration` 本地分支开发。没有修改 main，没有提交或推送。Logo 为参考原徽章简化重绘的透明 SVG。

## 首次安装

需要 Windows、Python 3.11+、Node.js 22.19+、Docker Desktop。先打开 Docker Desktop。所有命令从本项目根目录执行。

```powershell
& .\scripts\setup-local.ps1 -PythonPath '你的 Python.exe 绝对路径'
& .\scripts\configure-local.ps1
& .\scripts\start-local.ps1
```

已有可用的 `python` 命令可省略 `-PythonPath`。配置脚本隐藏输入 DeepSeek Key，保存到被 Git 忽略的根目录 `.env.local`，不在网页中显示。数据库默认使用团队本机 qodex 开发实例和现有数据卷。队友在另一台电脑执行迁移只会创建结构，不会获得你本机的题库数据；需要自己导入、解析并审校入库。

启动命令依次启动 PostgreSQL、应用已有 Alembic 迁移和命题待审表 SQL，然后启动三个 Python 服务和网页。网页地址为 http://127.0.0.1:3000 。保持窗口打开，Ctrl+C 只停止本轮启动的进程，保留数据库及数据卷。不会静默接管旧进程；端口被占用时先关闭旧服务窗口。

首次安装会按锁文件安装依赖并准备 Pi SDK 的所有依赖包。后续改动 Pi 源码时从 `pi-coding-agent` 执行 `node scripts/prepare-qodex-web.mjs`。只修改网页时可直接启动。现有 Bash `npm run demo` 仍可用，本版另提供 Windows 启动流程。

## 页面与真实服务

| 页面 | 已接入的功能 |
| --- | --- |
| 工作台 | 完整 Pi SDK 对话、流式文本、工具执行、会话列表、取消和排队；模型选项由真实 Pi 模型目录读取 |
| 命题与审校 | PDF/DOC/DOCX 上传解析、按文档编号加载、整卷审校、单题状态/版本/审校、基于固定版本 AI 修订与重审 |
| 命题高级面板 | single、batch、comprehensive、revise 原有 HTTP 操作；JSON 请求、原始返回与待审入队回执 |
| 正式题库 | 科目、关键词、难度查询；题面、选项、教师答案、来源编号与版本；最多 100 条，无虚构总数 |
| 智能组卷 | 单选题、整数分值、知识点/难度配额、正式题库读取、教师复核决定 JSON、真实组卷与历史保存 |
| 组卷历史 | 真实数据库分页、当前页名称/编号搜索与状态过滤、成功/缺题/待复核/异常结果 |
| 试卷详情 | 不可变学生题面快照、教师答案独立预览、两份 HTML 独立下载、打开后使用浏览器打印为 PDF |

表单中的初始三题配置对应作者本机现有题库的知识点，只是可编辑的需求默认值，不包含模拟题。其他题库请先用“读取题库知识点”核对精确名称、难度及原始分值。没有题库时会显示空结果或真实缺题，不会回退到 JSON 模拟题库。

历史页面每页 20 条，搜索和状态过滤明确仅作用于当前页。请求名称写入现有 request_id；不会修改数据库结构增加可变标题。需要全库模糊搜索、修改标题或全库统计时可另增接口，不在本版伪装为已支持。

## 本地验收顺序

1. 顶部“业务服务”检查 8091、8092、8093。模型状态与业务服务状态分开显示。
2. 正式题库点击“查询题库”，确认有真实题目；空表时先准备审校通过题目。
3. 智能组卷设置与题库匹配的知识点、难度和原始分值，检查配额，点击“开始组卷”。成功后自动进入该次历史。
4. 学生试卷和答案分别预览、下载。刷新页面或重启服务后，仍应读取同一历史快照。
5. 故意请求超出题库的配额，应返回题量不足并保存报告，不能下载残缺试卷。
6. 在命题高级面板加载项目单题示例，提交后检查 queue_receipts。它只是待审题，不等于已审校入库。
7. 配置 Key 后在 Pi 对话中执行一次题库只读查询，确认模型→工具→真实题库链路。命题与审校上传一个 10 MB 以下的试卷，取得 document_id 后再执行审校；不要重复解析同一个文件。

网络异常或长时间等待时，保留文档编号/组卷编号并先查询状态。页面不会自动重发组卷、解析或修订请求。`request_id` 不是组卷幂等键。MinerU 若受 TUN 代理影响，需要为 MinerU 及结果 CDN 配置可访问的网络路线。

## 队友交付边界

配置文件、密钥、Python/Node 依赖、数据库内容和 `.local` 证据均不提交。代码与迁移可提交到本功能分支，队友拉取后按本说明准备自己的实例并测试。不要提交虚拟环境或打包含密钥的运行目录。

当前是监听 127.0.0.1 的本机教师工作台，不是公开多用户网站。接口仅在 development 开启，并限制本机 Host 和同源访问。试卷 HTML 在无脚本沙箱中预览；答案走独立地址。本版没有登录/角色授权，不应开放到公网或直接作为学生门户。

命题待审队列还没有自动送到审校服务；保留现有操作能力，未擅自编造“全自动命题到入库”流程。相似题报告与人工决定通过已有 JSON 契约对接，未将字面相似检查称为语义质量认证。
