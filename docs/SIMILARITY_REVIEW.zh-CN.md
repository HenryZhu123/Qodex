# 相似题筛查与人工复核

## 当前能力

生产组卷服务已经接入字面相似筛查。原有离线 `main.py` / `pi_bridge.py` 开发演示仍保留原来的结构检查入口；新流程由 `assemble_with_similarity` 提供，正式服务默认调用它。

### 确定重复

沿用“不在同一卷保留相同规范化题干”的既有结构规则。仅统一 Unicode 全半角和空白，不删除数字、否定词、公式运算符或标点。

当题干相同、选项内容相同但顺序不同，会增加 `OPTION_ORDER_CHANGED` 依据。此类重复使用原来的配额联合重选流程尝试换题，不改写题干、选项或答案。

这里的“确定”指该结构规则或明确提供的人工结论，不是系统已认证了所有语义关系。同题干但选项不同也仍受原结构规则限制。

### 疑似重复

逐一比较选中试卷中的所有题对，保留文字相似度、选项重合度、数字变化等依据：

- 长度至少12字符，数字不同但替换数字后的文字模板相同。
- 长度至少12字符、文字相似度至少0.86、选项集合重合度至少0.5。
- 长度至少18字符、文字相似度至少0.95。
- 长度至少12字符、选项重合度至少0.75、文字相似度至少0.65。
- 非相同题干超过2000字符时不执行昂贵的字面比较，交人工处理并注明超限原因。

这些是固定的启发式规则，尚未经真实题对数据校准。同知识点、同答案或高相似度本身都不自动成为语义重复结论。完全换一种说法的重复题仍可能漏检；改变数字、增加否定词的正常不同题也可能被标记。

没有待复核标记时仍返回 `semantic_quality_certified=false`。没有接入 embedding、大模型语义判断或跨题答案泄露检查。

## 等待复核

有疑似题时，顶层状态为 `UNRESOLVED`，`similarity_review.status` 为 `NEEDS_REVIEW`，不生成学生卷和答案卷。报告保存：

- `similarity_review_packet.json`：教师用题面、答案、题对、内容指纹和筛查依据。
- `similarity_decisions_template.json`：待填写的人工结论模板。
- `report.json`：当前状态及路径。

题对包含答案，不能作为学生卷发放；Pi工具返回路径及摘要，不直接返回完整题对包。

## 提交人工结论

保持原组卷要求，额外传 `similarity_decisions` 数组。先从当前模板复制下列原字段，不能猜写题号或哈希：

```json
{
  "pair_id": "从模板原样复制",
  "question_ids": ["从模板原样复制的题号1", "题号2"],
  "content_hashes": ["从模板原样复制的哈希1", "哈希2"],
  "source": "human",
  "reviewer": "实际填写人提供的标识",
  "verdict": "DISTINCT",
  "reason": "实际复核依据，例如两题的已知条件和推理任务不同"
}
```

上面是说明性占位，不是可直接提交的有效记录。pair_id必须是24位小写十六进制，哈希必须是64位小写十六进制；题号顺序也必须保持一致。

- `DISTINCT`：记录该题对可区分，继续检查其他选中题对。
- `DUPLICATE`：把该题对加入不能同时选中的约束，重新选题并复核整卷。
- `UNRESOLVED`：仍然等待，不视为通过。

换题后出现新的疑似题对时仍需复核，不能借用旧题对结论。旧的同题干结构禁用规则不会被DISTINCT覆盖。

新题目内容、答案或版本与哈希不符，未知题号、重复冲突结论、缺少审核人或理由，均停止输出并返回 `INVALID_OR_STALE_DECISIONS`。这不是数据库审校PASS：它只记录题对相似关系，不修改题库、审校记录或题目版本。

Pi只应转发用户明确提供的结论，不能自行编造审核人、理由或人工身份。`source=human` 目前是调用方声明，没有身份认证；不能把它当成可信人员签名。

## 换题和补题

相同题干修复与人工确认重复的换题共用 `max_repair_rounds` 上限。选题搜索仍有预算：

- 找到替代题后重新检查题数、分值、知识点、难度、重复题及新疑似题。
- 完整搜索证明没有替代组合：`NEEDS_QUESTIONS`，联合补题计划不能同时保留已确认重复的两题。
- 轮数或搜索预算耗尽：`UNRESOLVED`，不能断言全库缺题。

补题后仍需独立审校、正式入库，再重新组卷和相似题筛查。

## 已验证内容

48项核心测试（含17项本轮检测/复核测试）、20项服务测试、22项Pi与审校扩展测试通过。隔离PostgreSQL合成测试通过，来源表未改变。模板改数字、选项调序、相近改写、否定词、同知识点不同任务、超长文本、内容/版本变化和换题后的新疑似题均有测试。

离线演示为 `pi-coding-agent/services/exam-assembly/examples/demo_similarity.py`，结果写入 `outputs/similarity_demo`：

| 场景 | 结果 |
| --- | --- |
| 选项调序的相同题干，有替代题 | STRUCTURAL_PASS |
| 仅数字变化的疑似题，无人工结论 | UNRESOLVED / NEEDS_REVIEW |
| 模拟人工确认重复，有替代题 | STRUCTURAL_PASS |
| 模拟人工确认重复，无替代题 | NEEDS_QUESTIONS |
| 题目版本变化后复用旧结论 | UNRESOLVED |

演示中的PASS和人工结论全部是显式合成测试占位，非真实审校、非真实人员复核，不向正式题库写入。`pair_cases.json` 保存5组带测试期望的合成题对，不是独立标注的准确率评测集。
