本报告将“完整输出协议合规率”作为严格的 JSON 格式正确率，同时保留语法正确率和 Schema 正确率用于定位问题。
本类别将微调版任务卡固定的 `德语：拼写错误`、`德语：语法错误`、`德语：标点符号错误` 与标准答案的总标签 `语义不清` 视为同义 `error_type`；其余 JSON 约束不放宽。

### 4.2 回答语义

1. 先比较 `has_error`、错误数量及 `error_type`。
2. 有错误时继续匹配 `original_text` 和 `correction`。
3. 字段不能直接确定时，再由 Codex 离线结合 `description`、`suggestion`、`reason` 和题面复核。
4. 允许字段顺序、空格和说明措辞不同，但不允许漏报、误报或修改方向错误。
5. JSON 格式错误与语义错误分别计分；格式错误的回答仍可在语义层面判为正确。
