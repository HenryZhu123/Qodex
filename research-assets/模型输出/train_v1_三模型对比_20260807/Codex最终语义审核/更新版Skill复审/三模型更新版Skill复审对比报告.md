# train_v1 三模型更新版 Skill 复审对比

> 三个模型各234题，三种错误类型各78题；所有记录均完成字段核对和Codex语义审核。

## 评测口径

1. 依次核验 `has_error`、错误数量和 `error_type`。
2. Codex逐题审核错误定位与回答质量，不使用未经语义审核的自动结果。
3. 对明确由删除内容构造的语义不清题，只要模型识别正确缺失位置即通过；自行补充、占位符或与标准答案内容不同均不判错。
4. 漏检、无错题误报、错误类型/数量不符，以及没有识别实际缺失位置的回答仍判错。
