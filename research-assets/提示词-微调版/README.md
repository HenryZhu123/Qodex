# 试题审校短提示词（微调对照版）

本目录用于“原长提示词 vs. 简短提示词”对照实验，不修改 `提示词` 目录中的生产版原文。

## 覆盖范围

共 20 个类别任务卡，覆盖 12 个聚合训练集：

- 错别字、语义不清、选项结构错误、标点符号错误、信息缺失、题目与题型不一致、题目无解、答案泄露；
- 英语：拼写、标点；
- 法语：拼写、语法、标点；
- 德语：拼写、语法、标点；
- 日语：拼写、语法、逻辑、标点。

## 拼接方式

每条训练、验证和推理请求的 `system` 按以下顺序拼接：

1. `共享核心.txt`
2. 当前类别任务卡
3. `JSON约束.txt`

三部分之间使用一个换行分隔。训练与推理必须使用完全相同的文本、顺序、类别标签、chat template 和 JSON Schema 版本。

推理服务若支持严格 JSON Schema，应同时启用约束生成；程序仍需检查字段关系、原文定位和类别标签。Schema 只约束结构，不替代任务卡中的业务规则。

## 对照实验要求

长、短提示词两组固定相同的模型、数据、解码参数、JSON Schema、随机种子和评测集，只替换 `system` 文本。分别报告错误样本正确率、无错误样本正确率、完整语义正确率、协议合规率和误报率。
