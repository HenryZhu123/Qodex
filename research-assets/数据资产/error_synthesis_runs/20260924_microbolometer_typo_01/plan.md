# 阶段 1：错别字造错计划

- 运行编号：`20260924_microbolometer_typo_01`
- 目标：基于用户指定的 1 道光电基础简答题，构造 1 条仅含 1 处错别字的负样本。
- 原题数量：1；计划造错数量：1；占本次输出 100%。整数配额无需舍入。
- 错误类型：错别字。
- 二级类型配额：音近字误用 1 条（100%）；形近字误用 0 条；专业术语用字错误 0 条。
- 来源：现有训练集 1 条，外部来源 0 条。
- 题型：简答题；学科：光电基础。

## 造错约束

1. 只进行一次汉字替换，不增删文字，不修改 `Si`、标点、题目结构、数值或答案承载信息。
2. 优先选择可唯一定位、可通过单字替换精确恢复的双字词位置。
3. 替换字必须与原字同音或近音，且错误词在当前语境中明确不成立。
4. 保留完整题目；不得产生第二处错误或改变题目所问知识。
5. 往返校验必须能将错误文本精确恢复为原题。

## 排除项与风险

- 不使用漏字、多字、倒字、标点错误或英文/符号错误。
- 不修改“微测辐射热计”“红外焦平面阵列”“微桥”“Si读出电路”等核心术语，以避免把文字书写错误混同为知识性术语错误。
- 原题已存在于错别字训练集及其规范化派生文件中，且当前切分为 `train`。造错版本不得进入验证集或测试集；若并入数据集，应保留同一 `train` 血缘并标记为该原题的变体。
- 工作区内的多处命中主要是快照、规范化副本和模型评测产物，不计为多个独立来源。

## 数据格式

- 阶段 2 先写 `mutation_manifest.jsonl`，记录干净文本、错误文本、最小修改跨度、唯一锚点、二级类型、签名和理由。
- 若继续生成训练答案，沿用现有 `messages` 格式、当前错别字 system prompt 和 `reason/has_error/total_errors/errors` JSON 答案结构。
- 原始训练集不修改；最终结果仅写入本运行目录的新版本文件。
