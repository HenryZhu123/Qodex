# CanonicalSample.v3-lite 数据规范

本目录定义试题审校项目的精简统一规范样本。规范层保存题目事实、来源引用、任务标注和切分结果；完整提示词、训练参数、数据源公共属性及审计事件保存在其他资产中。

## 文件

- `统一规范样本_第3版精简结构定义.json`：JSON Schema Draft 2020-12 机器校验规则。
- `统一规范样本_示例.json`：通过Schema校验的有错误样本示例。
- `D:\hyt-agent\Python脚本\validate_canonical_samples.py`：JSON或JSONL校验工具。

## 核心设计

### 保留生产输入原文

当前训练数据的用户输入固定为：

```json
{
  "reference": "...",
  "detection_content": "..."
}
```

规范层将它原样保存在 `question.input_payload`。`question.metadata` 只保存能够可靠获得的语言、学科、年级和题型；无法确定的字段直接省略，禁止猜测。

### `gold` 与生产输出完全同构

`annotation.gold` 直接保存真实assistant目标，不再使用字段映射或规范化别名。字段固定为：

```json
{
  "reason": "一句话结论。",
  "has_error": true,
  "total_errors": 1,
  "errors": [
    {
      "error_type": "当前任务固定类别",
      "position": "人类可读的位置",
      "original_text": "最短连续原文",
      "anchor_text": "可唯一检索的连续上下文",
      "correction": "修改后的内容",
      "description": "错误说明",
      "suggestion": "明确修改指令"
    }
  ]
}
```

SFT导出时将 `annotation.gold` 原样序列化为assistant消息，只允许JSON格式化差异，不允许字段改名或语义转换。`total_errors` 虽可由数组长度推导，但为保持真实输出协议仍然显式保存，并由校验器检查一致性。纯缺失错误可以使用空 `original_text`，但必须提供可检索的 `anchor_text` 和明确位置。

### 不进入规范样本的字段

以下信息不在每条规范样本中重复：

- `source_uri`、源文件SHA256、授权和脱敏版本：进入 `SourceManifest`。
- `task_card_version`、`prompt_bundle_sha256`：进入 `TrainingExample` 或 `DatasetManifest`。
- `split_policy_version`：进入 `DatasetManifest`。
- 完整修改历史：进入独立追加式审计日志。

## 必须满足的跨字段规则

JSON Schema负责字段类型和基本条件，校验工具额外检查：

1. `annotation.task_id` 必须出现在 `scope.annotated_task_ids` 中。
2. `total_errors` 必须等于 `errors` 数量。
3. `has_error=true` 时至少有一个错误；`has_error=false` 时必须为 `false / 0 / []`。
4. 非空 `original_text` 和 `anchor_text` 必须能够在 `detection_content` 中原样检索。
5. 无法确认血缘时使用 `lineage_status=needs_review`，不得伪造已验证血缘。
6. 血缘切分完成前使用 `split=unassigned`；同一 `lineage_id` 后续不得跨split。

错误类型与 `task_id` 的对应关系由后续 `TaskCatalog` 统一管理，不在Schema中硬编码中文枚举，避免每次新增任务都修改核心Schema。

## 与SFT训练文件的关系

规范样本不是直接喂给模型的文件。导出器根据规范样本和指定版本的提示词生成：

```json
{
  "sample_id": "cs_...",
  "lineage_id": "ln_...",
  "task_id": "ambiguity_check",
  "messages": [
    {"role": "system", "content": "生产提示词"},
    {"role": "user", "content": "[INPUT_PAYLOAD]\n{...}"},
    {"role": "assistant", "content": "生产JSON标准答案"}
  ],
  "loss_mask": "assistant_only",
  "sample_weight": 1.0
}
```

模型接收序列化后的 `messages`；`sample_id`、`lineage_id` 和来源信息只用于训练管理、统计和追溯。

## 校验

校验示例：

```powershell
python D:\hyt-agent\Python脚本\validate_canonical_samples.py `
  --schema D:\hyt-agent\数据资产\schemas\v1\统一规范样本_第3版精简结构定义.json `
  D:\hyt-agent\数据资产\schemas\v1\统一规范样本_示例.json
```

校验工具支持单个JSON对象、JSON对象数组和逐行JSONL。
