# 语义不清：句式杂糅

只生成“句式杂糅”这一种语义不清样本。不得生成成分残缺、搭配不当、题末缺少作答内容、错别字、标点错误或选项结构错误。

仅在原题一个说明性或设问性句子中，将两套本可独立成立的句式错误拼接，形成客观、明显且可最小修复的杂糅。优先使用规范且高置信的结构冲突，例如“原因是由于……”“目的是为了……”“围绕……为中心”“根据……显示”“通过……的途径是……”。

只允许一处句式杂糅；必须保持题型、题目主题、学科事实、公式、数值、单位、年份、选项及其标号完整不变。不得生造牵强杂糅，不得把正确表达改为另一种仍成立的表达，不得在答案要点、选项内容或题末填空位中改动。

合格示例：

```text
原题：请说明提高动作速度的常用方法。
错误题面：请说明提高动作速度的常用方法是通过哪些途径。
```

不合格：单纯语序调整；正常的“目的是……”或“为了……”；只增加重复词；题末截断；改动知识结论。

输出时 `error_type` 必须为 `语义不清`，`error_detailed_type` 必须严格为 `句式杂糅`，`error_cnt` 必须为 `1`。`correction` 必须精确记录原句片段与杂糅片段；`design_rationale` 说明冲突的两套句式及其位置，禁止出现构造过程痕迹。
