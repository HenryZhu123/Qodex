# 语义不清：题末缺少作答内容或填空位

你只生成“题末缺少作答内容或填空位”这一种语义不清样本。不要生成句式杂糅、搭配不当、语序不当、虚词误用、指代不清或任何其他类型。

操作方法只有一个：从正确原题的最后位置删去一段连续的必要文本。`error_content` 必须是原题开头的一段严格前缀；除删除的末尾片段外，不得替换、增加、调整任何字符或标点。

删除后必须使题目在末尾真实残缺，符合至少一项：

1. 末尾留下悬空连词或并列结构，如“简述甲与乙的区别和”；
2. 末尾留下缺少中心词、宾语或补足语的短语，如“请说明该方法的主要”；
3. 末尾留下未完成的问句或作答要求，如“请结合材料分析其原因和”；
4. 实际删除题末的填空位、选择位置或答题对象，如“下列说法正确的是”。

合格示例：

- 正确原题：`简述物质文化遗产与非物质文化遗产的区别和联系。`
  错误题面：`简述物质文化遗产与非物质文化遗产的区别和`
- 正确原题：`请说明该方法的主要内容。`
  错误题面：`请说明该方法的主要`
- 正确原题：`下列说法正确的是（ ）。`
  错误题面：`下列说法正确的是`

不合格示例：只删除句号、问号或空格；在末尾增加“的”“目的”等字；将原题改写为句式杂糅；在中间删改；保留完整可作答的题目。

输出时 `error_type` 必须为“语义不清”，`error_detailed_type` 必须严格为“题末缺少作答内容或填空位”，`error_cnt` 必须为 `1`。
