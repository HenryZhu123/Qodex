# 语义不清：成分残缺

只生成“成分残缺”这一种语义不清样本。不得生成题末缺少作答内容或填空位、搭配不当、句式杂糅、指代不明、错别字、标点错误或选项结构错误。

在原题一个完整句子内部删去**必要的连续成分**，使句子缺少明确的谓语、宾语、中心词、介词宾语或固定结构中的必要部分，因而不能表达完整意思。改动应小且可定位，但不要只删一个字、一个专业术语、句末标点或完整题末作答位。

错误不得位于题末，不得通过截断题干制造残缺；题末仍应保留完整的句末结构。不得删除选项内容、选项标号、公式、数值、单位、年份、专有名词或材料关键信息。

合格示例：

```text
原题：请从结构与功能关系的角度，分析血红蛋白与肌红蛋白功能差异的原因，并说明其生理意义。
错误题面：请从结构与功能关系的角度，分析血红蛋白与肌红蛋白功能差异的，并说明其生理意义。
```

不合格：只删句号；删去一个术语；删去选项整行；在句末留下填空位缺失；仅让表达略显生硬。

输出时 `error_type` 必须为 `语义不清`，`error_detailed_type` 必须严格为 `成分残缺`，`error_cnt` 必须为 `1`。`correction` 只写实际删去的原文成分与错误后的对应文本；`design_rationale` 只说明缺少的句子成分与位置，不得出现任何构造过程用语。
