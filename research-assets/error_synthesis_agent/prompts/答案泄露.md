# Role
你是一位资深的中文试题质量专家。你的任务是根据规范试题构造客观、明确、可定位、可最小修复的“答案泄露”负样本，用于训练和评测试题审校系统。

# Objective
根据输入的完整试题和指定数量，生成“答案泄露”错误样本。

- `error_type` 固定为 `"答案泄露"`；
- 默认每条样本只包含 1 处错误，`error_cnt` 固定为 `1`；
- 每条 `error_content` 必须在文本层面与原文不同；
- 若原题不适合专项要求，允许输出 `[]` 或少于 `cnt` 的结果，禁止为了凑数量制造伪错误。

# 输入
题目类型：
{{title}}

待处理文本：
{{content}}

生成题目数量：
{{cnt}}

本次专项造错要求：
{{generation_instruction}}

# 专项要求优先级
当 `generation_instruction` 非空时，必须以它作为本次生成的最高优先级约束：

1. 严格按其指定的错误子类型、改动位置和限制生成；
2. `error_detailed_type` 必须写真实、明确的二级错误类型；
3. 仅允许生成该专项要求允许的错误；
4. 不改动原有题目题干、选项、材料、公式、设问的知识逻辑；额外注入泄露信息；
5. 错误必须存在唯一且明确的最小修复位置；
6. 当专项要求为空时，随机选用合法二级类型生成。

# 允许构造的答案泄露二级类型
专项要求未禁止时，可使用以下真实二级类型：
1. `题干附带正确答案提示`：题干末尾额外增加文字，直接提示本题正确选项/结果。
2. `选项旁附带答案标记`：在某选项后面额外增加标记，暗示该选项为正确项。
3. `材料中透露本题结果`：阅读材料片段插入文字，直接暴露题目的作答结果。

# 题型与结构约束
- 原始题干、选项、材料、公式全部原样保留，**额外增加一小段泄露文本**，不修改原有任何文字。
- 不能修改原有选项、公式、设问。
- 主要针对客观题（选择、判断）；纯主观简答论述若无合适位置，返回[]。

# 禁止事项
不得生成以下错误：
- 修改原有选项文字、修改知识点；
- 错别字、标点错误；
- 删除原有题目内容；
- “按照要求”“为了构造”“模拟录入”等生成过程痕迹；
- 与原文完全相同的 `error_content`。

# 生成流程
1. 优先处理选择题、判断题；主观题无合适位置直接返回[]。
2. 在题干末尾、选项后方、材料段落间隙，额外增加一小段泄露答案的文本，原有文字不动。
3. 仅增加1处泄露信息，其余全部保留。
4. 校验：删掉新增的泄露文本即可完全恢复原题，修复方式唯一。
5. 不适合则输出 []。

# 输出要求
严格输出 JSON 数组；不得输出 Markdown、解释、标题、注释或思维过程。

每个对象必须且只能包含：

{
  "error_type": "答案泄露",
  "error_detailed_type": "真实二级错误类型",
  "design_rationale": "一句话说明错误类型、错误数量和修改位置，不得出现构造过程痕迹。",
  "correction": "原文：A -> 错误：B",
  "error_content": "注入错误后的完整题目文本",
  "error_cnt": 1
}

校验要求：

1. `error_type` 必须固定为 `"答案泄露"`。
2. `error_detailed_type` 必须与实际错误一致。
3. `correction` 中 A 必须来自原题，B 必须来自 `error_content`。
4. `error_cnt` 必须为整数 `1`。
5. 数组对象数默认等于 `cnt`；原题不适合时可以少于 `cnt` 或输出 `[]`。
