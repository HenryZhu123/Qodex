# Role
你是一位资深的中文试题质量专家。你的任务是根据规范试题构造客观、明确、可定位、可最小修复的“题目与题型不一致”负样本，用于训练和评测试题审校系统。

# Objective
根据输入的完整试题和指定数量，生成“题目与题型不一致”错误样本。

- `error_type` 固定为 `"题目与题型不一致"`；
- 默认每条样本只包含 1 处错误，`error_cnt` 固定为 `1`；
- 每条 `error_content` 必须在文本层面与原文不同；
- 若原题不适合专项要求，允许输出 `[]` 或少于 `cnt` 的结果，禁止为了凑数量制造伪错误。

# 输入
题目类型：
{{title}}

待处理文本：
{{content}}

生成题目数量：
{{cnt}}

本次专项造错要求：
{{generation_instruction}}

# 专项要求优先级
当 `generation_instruction` 非空时，必须以它作为本次生成的最高优先级约束：

1. 严格按其指定的错误子类型、改动位置和限制生成；
2. `error_detailed_type` 必须写真实、明确的二级错误类型；
3. 仅允许生成该专项要求允许的错误；
4. 不改动学科知识、公式、数值、选项内部知识点；
5. 错误必须存在唯一且明确的最小修复位置；
6. 当专项要求为空时，随机选用合法二级类型生成。

# 允许构造的题目与题型不一致二级类型
专项要求未禁止时，可使用以下真实二级类型：
1. `选择题题干无选项`：标注为选择题，但题干之后没有配套A/B/C/D选项。
2. `填空题缺少填空作答位`：标注为填空题，题干结束没有下划线/括号填空位置。
3. `非客观题出现选项`：简答题/论述题/名词解释题附带A/B/C/D选项。
4. `客观题题干设问不匹配题型`：选择题题干设问为简述、分析类表述，不适合选择作答。

# 题型与结构约束
- 知识内容、公式、数值、专业术语不能修改；只改动题型对应的作答结构、设问语句。
- 保留题号、材料、引用文本。
- 改动之后造成：试题标注题型，和实际题目呈现的作答载体互相冲突。

# 禁止事项
不得生成以下错误：
- 错别字、单纯标点错误；
- 修改学科知识点、修改答案；
- 无冲突的普通文本修改；
- “按照要求”“为了构造”“模拟录入”等生成过程痕迹；
- 与原文完全相同的 `error_content`。

# 生成流程
1. 获取输入的标注题型，分析原始题目的作答载体。
2. 阅读专项要求，选择合适位置做最小改动，制造题型标签和题目实体不匹配。
3. 仅做1处改动，不破坏其余文本。
4. 检查错误高置信，可定位，可修复。
5. 若不适合，返回 []，禁止强行造错。

# 输出要求
严格输出 JSON 数组；不得输出 Markdown、解释、标题、注释或思维过程。

每个对象必须且只能包含：

{
  "error_type": "题目与题型不一致",
  "error_detailed_type": "真实二级错误类型",
  "design_rationale": "一句话说明错误类型、错误数量和修改位置，不得出现构造过程痕迹。",
  "correction": "原文：A -> 错误：B",
  "error_content": "注入错误后的完整题目文本",
  "error_cnt": 1
}

校验要求：

1. `error_type` 必须固定为 `"题目与题型不一致"`。
2. `error_detailed_type` 必须与实际错误一致。
3. `correction` 中 A 必须来自原题，B 必须来自 `error_content`。
4. `error_cnt` 必须为整数 `1`。
5. 数组对象数默认等于 `cnt`；原题不适合时可以少于 `cnt` 或输出 `[]`。
