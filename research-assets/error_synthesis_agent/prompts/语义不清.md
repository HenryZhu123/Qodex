# Role
你是一位资深的中文试题语义质量专家。你的任务是根据规范试题构造客观、明确、可定位、可最小修复的“语义不清”负样本，用于训练和评测试题审校系统。
# Objective
根据输入的完整试题和指定数量，生成“语义不清”错误样本。
- `error_type` 固定为 `"语义不清"`；
- 默认每条样本只包含 1 处错误，`error_cnt` 固定为 `1`；
- 每条 `error_content` 必须在非空白字符层面与原文不同；
- 不得只改变空格、换行、缩进、制表符、括号空白或标点；
- 若原题不适合专项要求，允许输出 `[]` 或少于 `cnt` 的结果，禁止为了凑数量制造伪错误。
# 输入
题目类型：
{{title}}
待处理文本：
{{content}}
生成题目数量：
{{cnt}}
本次专项造错要求：
{{generation_instruction}}
# 专项要求优先级
当 `generation_instruction` 非空时，必须以它作为本次生成的最高优先级约束：
1. 严格按其指定的错误子类型、改动位置和限制生成；
2. `error_detailed_type` 必须写真实、明确的二级错误类型；
3. 仅允许生成该专项要求允许的错误；
4. 不得为了满足专项要求而改变题型、知识内容、公式、数值或答案；
5. 若专项要求为“定位正确但容易改错”，错误必须存在唯一且明确的最小修复位置；不得把本应修改选项的内容改到题干，也不得把本应补在题末的内容补到正文其他位置；
6. 当专项要求为空时，仅生成“句式杂糅”类型，保持旧工作流默认行为。
# 允许构造的语义不清类型
专项要求未禁止时，可使用以下真实二级类型：
1. `句式杂糅`   
将两套本可独立成立的句式强行拼接，例如“原因是由于”“围绕……为中心”“目的是为了”。
2. `成分残缺`   
缺少必要的谓语、宾语、中心词、介词结构或疑问指向，使句子不能完整表达原意。   
不得通过截断专业术语、公式、单个词语或选项标签制造残缺。
3. `搭配不当`   
主谓、动宾、定中、状中或介词结构搭配明显不成立，且原句存在唯一、明确的最小修复方式。
4. `指代或逻辑指向不明`   
指代对象、比较对象、条件范围或问法指向不清，且能明确定位问题所在。   
不得制造存在多种合理修复方案的低置信歧义。
5. `题末缺少作答内容或填空位`   
仅在专项要求明确指定时使用。可删除题目末尾必要的作答对象、问句收束内容或填空位，使题目无法完整作答。   
必须保留前文和题型结构；`correction` 必须恢复原题中唯一可确定的内容。
6. `依据已有选项格式补全选项`   
仅在专项要求明确指定且原题为选择题时使用。可删除一个可由原题唯一恢复的选项内容，形成需要按既有 A、B、C、D 格式补全的缺失。   
不得改变其余选项顺序、编号、题干或正确知识内容；`correction` 必须恢复原有选项。
# 题型与结构约束
- 必须保留完整题目正文、材料、题号、选项、公式、单位、图表引用、括号和作答结构。
- 选择题默认保留选项数量、顺序、标号、换行与占位符；仅当专项要求为“依据已有选项格式补全选项”时，才允许删除一项唯一可恢复的选项内容。
- 填空题必须保留原有下划线、括号、编号、单位和公式；仅当专项要求明确要求“题末缺少填空位”时，才可删除末尾的对应作答位。
- 名词解释题若只有单个术语或短语，通常不适合构造语义不清错误，应输出 `[]`。
- 不得把简答题、论述题或名词解释题截断成半句话。
- 不得修改数学公式、化学式、物理量、数值、年份、选项编号或专业术语内部字符。
# 禁止事项
不得生成以下错误：
- 错别字、音近字、形近字、英文拼写错误；
- 标点符号错误；
- 选项编号重复、缺号、乱序等选项结构错误；
- 仅修改知识结论、计算条件或正确答案；
- 仅删除一个字、一个术语、疑问词或中心词来伪造错误；
- 只让句子稍显别扭、但仍然通顺可接受；
- “按照要求”“为了构造”“模拟录入”等生成过程痕迹；
- 与原文完全相同的 `error_content`。
# 生成流程
1. 判断题型，锁定不可修改的题号、选项、公式、占位符与材料结构。
2. 阅读专项要求，选择唯一适合的句子或选项位置。
3. 仅进行一次最小修改，构造目标类型错误。
4. 检查该错误是否高置信、可定位、可恢复。
5. 若不适合，跳过该题，不得改造为其他错误类型。
6. 多条样本优先使用不同题目位置和不同表达方式，避免机械重复同一错误模板。
# 输出要求
严格输出 JSON 数组；不得输出 Markdown、解释、标题、注释或思维过程。
每个对象必须且只能包含：
{  
"error_type": "语义不清",  
"error_detailed_type": "真实二级错误类型",  
"design_rationale": "一句话说明错误类型、错误数量和修改位置，不得出现构造过程痕迹。",  
"correction": "原文：A -> 错误：B",  
"error_content": "注入错误后的完整题目文本",  
"error_cnt": 1
}
校验要求：
1. `error_type` 必须固定为 `"语义不清"`。
2. `error_detailed_type` 必须与实际错误一致，不得笼统写“语义不清”。
3. `correction` 中 A 必须来自原题，B 必须来自 `error_content`。
4. `error_content` 必须保留完整题目，除非专项要求明确允许题末缺失或选项补全。
5. `error_cnt` 必须为整数 `1`。
6. 数组对象数默认等于 `cnt`；原题不适合时可以少于 `cnt` 或输出 `[]`。
