(2y - 3x)\mathrm{d}x + (2x - 5y)\mathrm{d}y = 0
$$

$$
y(1) = 1
$$  
的解为

### EXPLANATION

设微分方程为  
$$
M\, dx + N\, dy = 0,
$$  
其中  
$$
M = 2y - 3x, \quad N = 2x - 5y.
$$

计算  
$$
\frac{\partial M}{\partial y} = 2, \quad \frac{\partial N}{\partial x} = 2,
$$  
故方程为恰当方程。

积分  
$$
\Psi(x,y) = \int M\, dx = \int (2y - 3x) dx = 2yx - \frac{3}{2}x^{2} + h(y).
$$

对$y$求偏导并与$N$比较，
$$
\frac{\partial \Psi}{\partial y} = 2x + h'(y) = N = 2x - 5y,
$$
得
$$
h'(y) = -5y,
$$
积分得
$$
h(y) = -\frac{5}{2} y^{2} + C.
$$

故通解为
$$
2xy - \frac{3}{2} x^{2} - \frac{5}{2} y^{2} = C.
$$

代入初值 $x=1, y=1$，得
$$
2 \cdot 1 \cdot 1 - \frac{3}{2} \cdot 1^{2} - \frac{5}{2} \cdot 1^{2} = 2 - \frac{3}{2} - \frac{5}{2} = 2 - 4 = -2 = C.
$$

所以解为
$$
2xy - \frac{3}{2} x^{2} - \frac{5}{2} y^{2} = -2.
$$

### ANSWER

$$
2xy - \frac{3}{2} x^{2} - \frac{5}{2} y^{2} = -2

## QUESTION 18

### QUESTION TYPE

proof

### QUESTION

设函数  $f(x)$  在  $x = 0$  处连续,且  
\[
\lim_{x\to 0}\frac{x f(x) - \mathrm{e}^{2\sin x} + 1}{\ln(1 + x) + \ln(1 - x)} = - 3
\]
证明  $f(x)$  在  $x = 0$  处可导,并求  $f^{\prime}(0)$

### ANSWER

分析极限式子：

\[
\lim_{x \to 0} \frac{x f(x) - e^{2 \sin x} + 1}{\ln(1+x) + \ln(1 - x)} = -3
\]

注意：

\[
\ln(1+x) + \ln(1 - x) = \ln(1 - x^{2}) \sim -x^{2}
\]

同时考虑$e^{2 \sin x}$的展开：

\[
\sin x \sim x, \quad e^{2 \sin x} \sim 1 + 2x + 2x^{2}
\]

将上述代入，分子近似为：

\[
x f(x) - \left(1 + 2x + 2x^{2}\right) + 1 = x f(x) - 2x - 2x^{2}
\]

极限可写为：

\[
\lim_{x \to 0} \frac{x f(x) - 2x - 2x^{2}}{- x^{2}} = -3
\]

整理为：

\[
\lim_{x \to 0} \frac{x(f(x) - 2) - 2 x^{2}}{- x^{2}} = -3
\]

分子分母同除以$x^{2}$：

\[
\lim_{x \to 0} \frac{\frac{f(x) - 2}{x} - 2}{-1} = -3
\]

即

\[
\lim_{x \to 0} \frac{f(x) - 2}{x} - 2 = 3 \Rightarrow \lim_{x \to 0} \frac{f(x) - 2}{x} = 5
\]

由此，$f$在$x=0$处可导，且

\[
f(0) = 2, \quad f'(0) = 5
\]

$f'(0) = 5$

## QUESTION 19

### QUESTION TYPE

short_answer

### QUESTION

设函数  $f(x,y)$  可微且满足  
\[
\mathrm{d}f(x,y) = - 2x \mathrm{e}^{-y} \mathrm{d}x + \mathrm{e}^{-y} (x^{2} - y - 1) \mathrm{d}y
\]
且  $f(0,0) = 2$ ，求  $f(x,y)$ ，并求  $f(x,y)$  的极值.

### EXPLANATION

由微分形式知：

\[
f_x(x,y) = -2x e^{-y}, \quad f_y(x,y) = e^{-y} (x^{2} - y - 1)
\]

先对$x$积分：

\[
f(x,y) = \int f_x(x,y) \mathrm{d}x = - e^{-y} x^{2} + h(y)
\]

对$y$求偏导，与$f_y$相比较：

\[
\frac{\partial f}{\partial y} = \frac{\partial}{\partial y} (- e^{-y} x^{2} + h(y)) = x^{2} e^{-y} + h'(y)
\]

令等于 $f_y$：

\[
x^{2} e^{-y} + h'(y) = e^{-y} (x^{2} - y - 1) \Rightarrow h'(y) = - e^{-y} (y + 1)
\]

积分得到：

\[
h(y) = - \int e^{-y} (y+1) \mathrm{d}y + C
\]

利用分部积分计算：

\[
\int (y+1) e^{-y} \mathrm{d}y = - (y + 1) e^{-y} + \int e^{-y} \mathrm{d}y = - (y + 1) e^{-y} - e^{-y} + C = -(y + 2) e^{-y} + C
\]

故

\[
h(y) = (y + 2) e^{-y} + C
\]

利用条件 $f(0,0) = 2$，得：

\[
f(0,0) = - e^{0} \cdot 0^{2} + h(0) = h(0) = (0 + 2) \cdot 1 + C = 2 + C = 2 \implies C = 0
\]

综上：

\[
f(x,y) = - x^{2} e^{-y} + (y + 2) e^{-y}
\]

极值条件，令梯度为零：

\[
f_x = \frac{\partial f}{\partial x} = - 2x e^{-y} = 0 \Rightarrow x = 0
\]

\[
f_y = \frac{\partial f}{\partial y} = x^{2} e^{-y} + (y + 1) e^{-y} = e^{-y} (x^{2} + y + 1) = 0 \Rightarrow x^{2} + y + 1 = 0
\]

联立得：

\[
x = 0, \quad y = -1
\]

计算 Hessian 判断极值类型。

### ANSWER

\[
f(x,y) = - x^{2} e^{-y} + (y + 2) e^{-y}
\]

极值点为 $(0, -1)$。

\[

\]

\[

\[
r \leq \min(4 \cos \theta, 4 \sin \theta).

## QUESTION 21

### QUESTION TYPE

proof

### QUESTION

设函数  $f(x)$  在区间  $(a,b)$  内可导.证明导函数  $f^{\prime}(x)$  在  $(a,b)$  内严格单调增加的充分必要条件是：

对  $(a,b)$  内任意的  $x_{1},x_{2},x_{3}$  ，当  $x_{1} < x_{2} < x_{3}$  时,  
\[
\frac{f(x_{2}) - f(x_{1})}{x_{2} - x_{1}} < \frac{f(x_{3}) - f(x_{2})}{x_{3} - x_{2}}.
\]

### ANSWER

证明分两部分：

1. 必要性：

若$f'(x)$严格单调增，则对任意$x_1 < x_2 < x_3$，

由Lagrange中值定理，

存在$\xi_1 \in (x_1, x_2)$及$\xi_2 \in (x_2, x_3)$，使得

\[
\frac{f(x_2) - f(x_1)}{x_2 - x_1} = f'(\xi_1), \quad \frac{f(x_3) - f(x_2)}{x_3 - x_2} = f'(\xi_2).
\]

由于$f'$严格增，故$f'(\xi_1) < f'(\xi_2)$，即条件成立。

2. 充分性：

若对任意$x_1 < x_2 < x_3$，不等式成立。

取任意$x < y$，构造序列$x=x_1 < x_2 < x_3=y$，则根据条件，导数极限不存在反向不等式，所以$f'(x)$严格单调增。

综上，条件等价于$f'$严格单调增加。

导函数  $f^{\prime}(x)$  在  $(a,b)$  内严格单调增加的充分必要条件为：

对任意  $a < x_1 < x_2 < x_3 < b$ ，有

\[
\frac{f(x_2) - f(x_1)}{x_2 - x_1} < \frac{f(x_3) - f(x_2)}{x_3 - x_2}.
\]
